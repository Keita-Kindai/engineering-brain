# Inbox

Human Learning と Engineering Brain の境界です。分類、metadata、重複排除を気にせず Markdown を置き、`brain-capture` で `knowledge/` に統合します。

- 1 file は原則 1 topic。
- Secret、private source、raw conversation は置かない。
- Coding session 由来の Human knowledge は `type: knowledge-candidate` と明記できる。
- `README.md` 自体は capture 対象外。
