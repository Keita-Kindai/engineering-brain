# Session memory index

- `recent/`: 通常検索対象。明示的 `brain-learn` または重要 Session のみ。
- `archive/YYYY/`: 他 memory へ十分蒸留された古い Summary。過去の試行を尋ねられた場合だけ検索。
- Filename: `YYYY-MM-DD-short-topic.md`
- Status: `active` または `distilled`
