# Knowledge index

Human が理解した semantic memory の地図です。本文をここへ集約せず、topic file へ link します。

| Area | Scope |
| --- | --- |
| `web/` | Web platform、framework、frontend / backend |
| `computer-science/` | Algorithms、OS、network、database、language fundamentals |
| `cloud/` | Cloud providers、containers、infrastructure |
| `machine-learning/` | ML、deep learning、evaluation、MLOps |
| `ai-agents/` | Coding agents、MCP、agent workflows |
| `nextjs/` | Next.js framework、request flow、authentication |

新しい Note を追加したら、必要な場合だけこの表の下に短い topic link を追加します。検索はまずこの index、次に `rg`、最後に候補本文の順です。
